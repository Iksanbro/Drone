# Иконки модов

`python3 mod-icons/draw_icons.py [мод ...]` (нужны numpy и Pillow, около 2–3 минут на иконку) рисует иконки четырёх модов в одном стиле: тёмно-синий фон, голубой круг с сеткой и белой объёмной обводкой, предмет мода в центре.

Предметы — настоящие 3D-сцены (поля расстояний, трассировка лучей на numpy): ключевой свет с мягкими тенями, затенение в углах, отражение неба в металле, голубой контровой свет. Рендер в 2048×2048 и уменьшение до 1024 сглаживают края.

Пишет `mod-icons/<мод>.png` (1024×1024, для аватара проекта на CurseForge) и `src/main/resources/icon.png` каждого мода (512×512, `logoFile` в `neoforge.mods.toml`). Быстрый предпросмотр: `ICON_SIZE=256 python3 mod-icons/draw_icons.py`.
