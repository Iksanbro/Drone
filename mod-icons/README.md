# Иконки модов

`python3 mod-icons/draw_icons.py` (нужен Pillow) рисует иконки четырёх модов 512×512 в одном стиле: тёмно-синий фон, голубой круг с сеткой и белой обводкой, предмет мода в центре. Кладёт их в `mod-icons/<мод>.png` и в `src/main/resources/icon.png` каждого мода (`logoFile` в `neoforge.mods.toml`). Эти же картинки подходят для аватара проекта на CurseForge.
