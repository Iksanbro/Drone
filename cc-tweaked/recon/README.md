# sniff — разведка модемного эфира (CC:Tweaked)

Пассивно слушает каналы и показывает, что по ним летает: канал, обратный
канал, расстояние до отправителя и само сообщение. Ничего не передаёт.

Нужен как первый шаг: узнать, на каком канале и в каком формате идёт
чужая связь. Без этого подделать команду нельзя.

## Запуск
1. Компьютер + эндер-модем. Поставьте поближе к источнику чужих сигналов.
2. `MODE="sweep"` — найти активные каналы (развёртка по всем 65536).
3. Нашли канал — впишите его в `WATCH`, поставьте `MODE="watch"`, перезапустите.
4. Полный дамп всех сообщений пишется в `sniff.log`.

## Что это даёт
- **Канал** связи противника.
- **Формат** сообщений (имена полей — их надо знать, чтобы что-то подделать).
- **Расстояние** до отправителя (`distance` в событии `modem_message`) —
  грубая засечка, где физически стоит его передатчик.

## Пределы
- Один модем держит открытыми максимум 128 каналов разом, поэтому развёртка
  идёт окнами и может пропустить редкую передачу. Для надёжности держите
  `sweep` подольше или слушайте известный канал в `watch`.
- Шифрованную/подписанную связь вы увидите, но не прочитаете содержимое.
