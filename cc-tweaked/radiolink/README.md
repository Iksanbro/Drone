# radiolink — радиоуправление для CC:Tweaked + Create Aeronautics

Передаёт сигналы с печатной машинки (Typewriter) на удалённый сублевел
с сохранением силы сигнала (0–15) и имени канала.

## Схема

    Печатная машинка --(частоты Redstone Link)--> Redstone Link (приём)
        --> компьютер tx.lua + эндер-модем
        ~~~ радио ~~~
        компьютер rx.lua + эндер-модем (на сублевеле)
        --> Redstone Link (передача) / провода --> механизмы дрона

## Установка

1. Передатчик: компьютер + **эндер-модем** (у беспроводного ограничена дальность).
   К каждой стороне — Redstone Link в режиме приёма на частоту нужной клавиши.
   Скопировать `tx.lua`, запустить `tx`.
2. Приёмник на сублевеле: компьютер + эндер-модем. С каждой стороны —
   Redstone Link в режиме передачи (или прямо провод к механизму).
   Скопировать `rx.lua`, запустить `rx`.
3. В обоих файлах одинаковые `CHANNEL`, `NETWORK`, `SECRET`.
   Имена в `INPUTS` (tx) и `OUTPUTS` (rx) должны совпадать.
4. Больше 6 сигналов — ставьте Redstone Relay и указывайте `relay = "redstone_relay_0"`.
5. Автозапуск: создайте `startup.lua` с `shell.run("tx")` или `shell.run("rx")`.

## Что гарантируется

- Аналоговая сила 0–15 передаётся как есть.
- Изменения шлются сразу, полное состояние — каждые 0.25 с (потерянный пакет не важен).
- Старые/повторные пакеты отбрасываются (номер пакета + id сессии).
- Нет связи дольше `FAILSAFE` секунд — все выходы в безопасное значение (`safe`, по умолчанию 0).
- Чужие сети/пароли игнорируются.

Важно: чанки с обоими компьютерами должны быть прогружены.
