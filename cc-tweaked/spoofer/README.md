# spoof — ложные цели для радара соперника (CC:Tweaked)

Шлёт на канал радара правдоподобные контакты, которые двигаются и меняются:
игроки, сублевелы Sable, снаряды и пушки CBC, мобы.

## Запуск
1. Компьютер + эндер-модем (или беспроводной, если радар рядом).
2. В `spoof.lua` укажите `CHANNELS` — каналы, которые слушает радар.
3. Поправьте `makeContact()` под формат сообщений радара (см. ниже).
4. `spoof`

## Как узнать канал и формат
Поставьте компьютер с модемом рядом и откройте все каналы по очереди
(`modem.open(ch)`), смотрите `modem_message`: канал, поля таблицы, частоту.
Скопируйте точные имена полей в `makeContact()`.

## Когда не сработает
- Радар сканирует сам (peripheral-сканер) и не принимает данные по модему —
  ложные цели появятся только у тех, кто получает его данные по сети.
- Радар проверяет отправителя (id компьютера, пароль, подпись) — пакеты отбросят.
- `SEND_BATCH`: если радар ждёт список целей одним пакетом — `true`, если по одной — `false`.

`RATE` держите 2–10. Сильнее не нужно: радар и так засорится, а сервер начнёт лагать.
