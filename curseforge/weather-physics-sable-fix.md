# Weather Physics Sable Fix

**Fixes the server crash "Body has been removed" in Weather Physics + Sable.** Tornadoes no longer take the whole server down when a Sable structure breaks apart under them.

---

## ✨ Features

### 🌪️ No more tornado crash
- When a Sable ship or structure **broke apart, merged or was destroyed** while a tornado was pulling at it, the server crashed with *"Body has been removed"*.
- Now the tornado simply skips that structure for a moment, and the game goes on.

### 🧘 Changes nothing else
- Tornadoes, wind, sails and Sable physics work exactly as before.
- Can be added to an existing world and removed again at any time.

---

## 🚀 Quick start
Put the jar into the `mods` folder — on the server, or in the game for singleplayer. That's it.

---

## 📦 Requirements
- Minecraft **1.21.1**, NeoForge **21.1.228+**
- **Weather Physics (Wind, Sails & Tornadoes)** 1.0.3+
- **Sable** 2.0+

Server-side: clients do not need the mod.
