# Рецепты последовательной сборки

Файл создан `tools/generate_data.py`, руками не править.

Рецепт есть только у деталей, которые делаются исключительно в мире (литьё и сверление),
и только если этот процесс в мире работает. Рецепт добавлен рядом с литьём, ничего не заменено.

Ресурсы те же, что у литья. Металл ×3, остальное в прежнем количестве:
форма держится в деплоере и не тратится (при литье она тоже возвращается).
Старт: один слиток материала. В каждом цикле часть металла идёт слитками (деплоер),
часть расплавом того же металла (дозатор), затем механический пресс и механическая пила.

Деталям, которым в мире после сверления нужен предмет (экстрактор, пружина), сборка даёт
incomplete-деталь, как после сверления. Затем деплоер ставит в неё этот предмет (один раз).

## Что мод добавляет, чтобы литьё работало

Формы (механическая пила, любое бревно `#minecraft:logs`):

- `cbc_at:twin_autocannon_barrel_mould` (рецепт CBC:AT 0.1.4c не загружается)
- `cbc_at:rocket_pod_rail_mould` (рецепт CBC:AT 0.1.4c не загружается)
- `cbc_at:rocket_pod_breech_mould` (рецепт CBC:AT 0.1.4c не загружается)
- `cbcmodernwarfare:rotarycannon_barrel_cast_mould` (в Neo Warfare 1.21.1 рецепта нет)
- `cbcmodernwarfare:rotarycannon_breech_cast_mould` (в Neo Warfare 1.21.1 рецепта нет)
- `cbcmodernwarfare:rotarycannon_bearing_cast_mould` (в Neo Warfare 1.21.1 рецепта нет)

Литьё и сверление роторных пушек (в Neo Warfare 1.21.1 их нет), бронза, сталь, незерсталь:

- литьё в форме `createbigcannons:rotarycannon_barrel` / `_breech` / `_bearing` → `unbored_<материал>_rotarycannon_*`;
- сверление: ствол → готовый ствол, казённик и подшипник → `incomplete_*`;
- в incomplete-казённик деплоером ставится экстрактор, в incomplete-подшипник — вал Create (так задано в Neo Warfare).

Экстрактор казённика роторной пушки (рецепта нет нигде):

| Предмет | Старт | Шаги |

| `cbcmodernwarfare:bronze_rotarycannon_breech_extractor` | `#c:ingots/bronze` | деплоер: `create:shaft` → пила → пресс |
| `cbcmodernwarfare:steel_rotaryannon_breech_extractor` | `#c:ingots/steel` | деплоер: `create:shaft` → пила → пресс |
| `cbcmodernwarfare:nethersteel_rotarycannon_breech_extractor` | `#c:ingots/nethersteel` | деплоер: `create:shaft` → пила → пресс |
