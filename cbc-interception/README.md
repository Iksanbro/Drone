# CBC Interception

Мод для **NeoForge 1.21.1**: снаряды Create Big Cannons и его аддонов можно сбивать выстрелами.

Снаряды, которые встретились в полёте, попадают друг в друга. Сбитый снаряд срабатывает так же, как при попадании в цель:

- фугасные, осколочные, шрапнельные, дымовые, жидкостные, кассетные снаряды, фугасные патроны автопушек и ракеты с боевой частью **взрываются в воздухе** в точке попадания;
- ракета CBC Enchanced Shells выпускает свою боевую часть и подрывает её, малая ракета из ракетной стойки взрывается;
- болванки, бронебойные снаряды и патроны, пули, ракеты без заряда **разрушаются** (обломки, звук).

Сбивающий снаряд тоже тратится: он попал во что-то. Если он сам фугасный, то тоже взрывается.

Чем можно сбить:

| Чем | Как работает |
|---|---|
| Прямое попадание любым снарядом | пути двух снарядов за тик проверяются целиком, поэтому быстрые снаряды не пролетают друг сквозь друга |
| Осколки (зенитные, шрапнель, картечь, канистры Neo Warfare) | каждый осколок проверяется так же, как снаряд |
| Взрыв рядом | снаряды в радиусе взрыва срабатывают |
| Неконтактный взрыватель (proximity fuze) | взведённый взрыватель срабатывает, когда чужой снаряд входит в его дистанцию. В CBC он реагирует только на существ и технику |

Снаряды одного залпа (спаренные стволы, очередь) друг друга не сбивают: снаряды, летящие вместе (разница скоростей меньше 1 блока за тик), не сталкиваются, и следующий снаряд очереди не взрывается от взрыва предыдущего. Только что вылетевший снаряд (первые 2 тика) не участвует.

## Какие снаряды

Все снаряды Create Big Cannons и всех аддонов, которые наследуют его класс снаряда: CBC: Advanced Technologies, CBC Neo Warfare, CBC Enchanced Shells и другие. Мод находит способ подрыва сам, без списка. Малая ракета CBC Enchanced Shells не снаряд CBC, она добавлена тегом.

Теги типов сущностей:

- `cbcintercept:interceptable`: добавить сущность другого мода (снаряд или ракету);
- `cbcintercept:not_interceptable`: исключить снаряд или тип осколков.

## Настройки

`config/cbcintercept-server.toml`:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `projectilesCollide` | `true` | весь мод |
| `extraHitRadius` | `0.5` | сколько блоков добавить к размерам двух снарядов при проверке попадания (0 — только касание) |
| `fragmentsHitProjectiles` | `true` | осколки сбивают снаряды |
| `explosionsHitProjectiles` | `true` | взрывы сбивают снаряды |
| `proximityFuzesReactToProjectiles` | `true` | неконтактные взрыватели срабатывают на снаряды |

Мод работает на сервере, клиентам ставить его не обязательно.

| Мод | Обязателен | Проверено на |

| NeoForge | да | 21.1.228 |
| Create Big Cannons | да | 5.11.7 |

| CBC Neo Warfare | нет | 0.0.6v |

## Сборка

Нужна Java 21.

```bash
cd cbc-interception
./gradlew build    # build/libs/cbc-interception-1.21.1-1.0.jar
```

### Тесты

```bash
./gradlew runGameTestServer                       # CBC + CBC:AT + Neo Warfare
./gradlew runGameTestServer -PwithoutAddons       # только Create Big Cannons
./gradlew runGameTestServer -PwithEnhancedShells  # плюс CBC Enchanced Shells 1.5.1 (-PenhancedShellsFile=8838000 для 1.2.5)
```

Тесты запускают снаряды навстречу друг другу высоко в воздухе и проверяют:

- два бронебойных патрона автопушки, летящие навстречу, разбиваются в точке встречи;
- два патрона одного залпа, летящие рядом, друг друга не трогают;
- фугасный снаряд, в который попал патрон, взрывается там, где в него попали;
- зенитный снаряд с взведённым неконтактным взрывателем срабатывает рядом с летящей болванкой и уничтожает её;
- с выключенными взрывами болванку уничтожают осколки;
- взрыв рядом с летящей болванкой уничтожает её;
- фугасный патрон Neo Warfare сбивается пулемётной пулей;
- ракета CBC Enchanced Shells сбивается патроном автопушки;
- с выключенной настройкой патроны пролетают друг сквозь друга;
- каждый тип снаряда в игре (52 с CBC:AT и Neo Warfare, 143 вместе с Enchanced Shells) подрывается или разрушается без ошибок.

## Ограничения

- Каменное ядро мортиры (`mortar_stone`) при попадании разрушается, а не взрывается: у него нет отдельного метода подрыва.
- Если у снаряда аддона подрыв падает с ошибкой (например, аддон собран под другую версию CBC), снаряд разрушается, а ошибка пишется в лог один раз. Так было в тестовой сборке с фугасными снарядами CBC:AT 0.1.4c и CBC 5.11.7.
- Осколки летят случайно: зенитный снаряд, взорвавшийся в стороне от цели, может промахнуться.
